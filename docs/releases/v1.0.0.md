Windows x64 桌面桌宠：透明置顶小窗 + 106 条手绘动画 + 托盘菜单 + 设置窗口（保存即生效）+ 可选的 AI 碎碎念/对话。

## 这一版有什么

- **全新的应用图标**：换成原子轨道图标（16/24/32/48/64/128/256 全尺寸阶梯 + 托盘 + 两处页头 logo 统一，另一套黑描边样式也留在仓库里）
- **修掉一条真实反馈的 bug**：托盘菜单的失败提示被窗口下边缘裁掉（用户报的"下面的提示文字显示不全"）
- **打包卫生**：安装包里不再附带开发用的测试程序（体积 −1.4 MB，MSI 的 File 表里原本有 `Bin_logic_smoke`）
- **首次启动会告诉你入口在哪**：Win11 默认把新出现的托盘图标收进「隐藏的图标」浮出层，第一次启动宠物会自己说一句（只提示一次）
- 界面文案精简：去掉上游痕迹，许可里补上本仓库地址

## 安装

| 文件 | 说明 |
| --- | --- |
| `whale-pet_1.0.0_x64-setup.exe` | **推荐**：NSIS 安装器，中文界面（61.7 MB） |
| `whale-pet_1.0.0_x64_zh-CN.msi` | MSI，适合企业部署 / 静默安装（62.8 MB） |

- 环境：Windows 10/11 x64 + WebView2 运行时（系统一般自带）
- 安装包**未做代码签名**，会提示「未知发布者」，选"更多信息 → 仍要运行"即可；为什么没签、四条签名路线各要多少钱、拿到证书后怎么接，都写在仓库 `docs/SIGNING.md`
- 首次启动会把随包素材释放到 `%APPDATA%\com.whalepet.desktop\`（106 条动画 + 表情包 + 气泡字体），**只补缺失，不覆盖你自己放的文件**
- 想换宠物：把 `.webm`（VP9-alpha）丢进数据目录的 `webm/`，在设置窗口里选它即可
