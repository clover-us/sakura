# 路线图

M0 已完成（验证结论见 [`VERIFICATION.md`](VERIFICATION.md)）。以下按里程碑推进，
每个里程碑都以"可运行、可验证"为出口标准，而不是"代码写完"。

## M0 技术验证 ✅

**目标**：证明 Tauri 能把这套桌宠跑起来，且四个高风险环节都成立。

- [x] 透明置顶小窗（`transparent` + `always_on_top` + `skip_taskbar` + `no shadow`）
- [x] VP9-alpha webm 透明播放（自定义协议 `pet://` 提供素材）
- [x] 点击穿透自愈（Rust 轮询全局光标 + 前端精确命中判定 + busy 保护）
- [x] 拖拽弹簧跟手 + 甩抛物理 + 逐屏边界 + 落地静止
- [x] 配置读取/校验/默认配置释放、诊断日志通道
- [x] 纯逻辑冒烟检查（39 项断言）

**出口标准**：全部通过（已达成）。

## M1 宠物本体补齐

**目标**：把上游桌宠的"行为"补齐到与现状一致（不含 LLM）。

- [x] **完整动画链**：待机/转向/移动/随机动作分类，按权重选下一个，播完立即衔接（上游 `pickers` / 配置的 `animations` / `animationWeights`）
- [x] **素材导入**：上游 106 个透明动画全部导入并按分类识别（`scripts/import-animations.ps1`）
- [x] **左右转向与镜像**：`noMirror` 文字类动作的朝向规则
- [x] **屏幕漫游**：朝 facing 方向行走 + 空间检查（上游 `motion.planMove`，需把 `pickers.ts` / `motion.ts` 一并拷进 `reference/shared`）
- [ ] **多宠物**：配置多写几项即可多开（窗口层已按"每宠一窗"设计，主要是补跨窗状态）
- [ ] **跨窗碰撞**：`petCollision` 开关生效（动量守恒 + 恢复系数 0.995；上游 `physics.collidePet` 可复用，Rust 侧需要一个状态 broker 广播各窗位置/速度）
- [x] **右键级联菜单**：动作分类点播（上游 `shared/menu.ts` 是"树 + 渲染"两份可复用代码）
- [x] **气泡独立小窗**：不可聚焦 + 整窗点击穿透的纯显示窗，跟随宠物头顶定位（`src-tauri/src/bubble.rs`）
- [ ] **点击积分**：飞行中被按下 → 粒子 + 积分卡片（上游 `score.ts` / `score-popup.ts`）
- [x] **角落定位语义统一**："回到初始位置"与启动定位共用 `anchorPixel`
- [ ] **高 DPI 回归**：125% / 150% 缩放下的尺寸与命中精度
- [ ] **多显示器回归**：跨屏抛掷、显示器插拔/改分辨率（`display.rs` 已有指纹轮询）

**出口标准**：在与 `dsh-pet` 桌面模式相同的配置下，行为一致（动作链、漫游、抛掷手感、菜单项）。

## M2 像个正经应用

- [ ] **设置窗口**：多开增删、大小/位置/边距、物理参数、动画池编辑（上游 `settings.ts` 的交互可参考，但要重写为独立的 Tauri 窗口）
- [ ] **托盘完整菜单**：显示/隐藏、回到初始位置、动作点播、设置、退出

- [ ] **开机自启**：`tauri-plugin-autostart`
- [ ] **配置热重载**：文件变更监听（目前需重启）
- [ ] **从 dsh-pet 导入**：一键迁移上游的 `main-config.json` / `main-animation/` / `pet/`
- [ ] **CSP 收紧**（见 [`TAURI-CONFIG.md`](TAURI-CONFIG.md)）

**出口标准**：不碰配置文件也能完成全部常用设置。

## M3 加分能力（需要自带 LLM）

- [ ] **LLM 适配层**：OpenAI 兼容 / DeepSeek / Ollama；API key 用 DPAPI（`keyring` crate）加密存
- [ ] **碎碎念**：按周期生成一句话 + 气泡（上游 `whisper.ts` 的 prompt 语义可复用）
- [ ] **对话与记忆**：`memory.json` 全存不删 + 最近 N 轮进上下文（上游 `chat.ts` 同构）
- [ ] **表情包配图**：碎碎念随机抽 / 对话按语境选（需要把 `assets/memes` 一并导入）
- [ ] **余额**：DeepSeek + OpenCode + 自定义接口（上游 `host/balance.ts` 的 provider 表可复用）

**出口标准**：默认关闭所有联网功能（保持"零成本桌宠"），开启后可用。
